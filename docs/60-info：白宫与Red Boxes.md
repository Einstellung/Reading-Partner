## 根问题

让注意力已排满的人在自己视野范围内不落后于时代：碎片时间听懂发生了什么，整块时间读懂重要的东西。目标用户是每天处理海量信息、渴望快速学习的城市人群。

六条推论：

| # | 推论 | 状态 |
|---|---|---|
| 1 | 两种产出对应两种时间：讲（语音、免手、可打断）和稿（多源聚合的专题稿，进书架，可划线可对话可蒸馏） | 从愿景直接推出 |
| 2 | 需求侧 = 视野（领域范围，用户声明）+ concern（dream 蒸出）；源是供给侧，与需求分开 | 用户已认 |
| 3 | 聚合是 legion run，即深挖 run 的主体 | 从愿景直接推出 |
| 4 | 碎片时间靠随时可用，不靠打扰：队列常备、从中断处接着听、不推送；锁屏播放与后台音频因此成为必需 | 用户已认 |
| 5 | 质量线见「管线与秘书」一节 | 从愿景直接推出 |
| 6 | 衡量覆盖与时效，不衡量过滤精度 | 从愿景直接推出 |

info 是 reading 的进水口之一。info 帮用户认识世界，reading 帮用户改造世界；两者在书架上接头——info 的稿和 info 收藏的文章都落到书架，之后走 reading 的那一整套。

## 白宫

比喻的骨架，后面各节用它的词。

| 白宫 | 我们 |
|---|---|
| 总统 | 用户 |
| Staff Secretary | 盒子的程序层：装盒、排序、记状态。不用模型 |
| PDB 简报员 | 秘书长的讲模式 |
| 各情报机构 | 各源组的管线 run，一个机构一个盒 |
| tasking | 深挖 run，结果回来又是一个盒 |
| decision memo | 聚合稿，进书架 |
| 决策备忘录的三个勾（Approve / Disapprove / Discuss） | saved / dismissed / asked |

一天：夜里各机构跑 run，各出一盒；早上用户看到几个没开的盒，简报员从最上面那盒念起；碎片时间从中断处接着听，新盒到了只入栈不推送；白天的提问变 tasking，结果傍晚回来又是一盒；夜读聚合稿；dream 把盒里的动作折进观察，关掉过期的盒，回收已蒸馏的原料。

## 盒子

**Red Boxes 是复数。** 一个盒子 = 一次投递 = legion 的一个 batch。管线跑一次出一盒，聚合 run 出一盒，tasking 回来出一盒，一天若干盒。用户看到的是「几个没开的盒子」，不是一条列表。

盒按机构切，即按源组；另有两类盒：tasking 回盒和稿送达盒。封面由模型写一段，其中的数字和日期由程序取。排序把要紧的放最上。「下一个」在盒内跳条，到底了换盒。有底靠盒的边，不靠存储容量——盒是有限的，读完就没了。

**cable。** 一条 cable 是一篇文章。溯源、处置、记忆三个最小单位在这里合一：正文、一页 brief、引文、程序算出的优先级输入（来源权重、concern 命中、新鲜度）、状态、用户批注，全部钉在同一份上。跨源的事件簇不在 cable 这一层合并，留给聚合 run。取这个名字是因为它是一封发进来的电报：有发报方、有到达时刻、处置结果写在同一张纸上。

状态集与出口：

| 词 | 类别 | 含义 |
|---|---|---|
| `in box` | 中间态 | 投进来了，还没到用户面前 |
| `told` | 中间态 | 秘书讲过了 |
| `asked` | 中间态 | 用户就它问过 |
| `later` | 中间态 | 明天再看。要不要有，待定 |
| `dismissed` | 出口 | 摁掉，或过期自动关 |
| `saved` | 出口 | 收进收藏 |
| `promoted` | 出口 | 精读，进书架 |
| `folded` | 出口 | 折进一条 concern 或 observation |
| `aggregated` | 出口 | 被一篇聚合稿消费 |

盒子有两个消费者：秘书讲，聚合 run 写稿。所以 `told` 与 `aggregated` 不互斥。

**文件形态。** 一条 cable 一个文件，随账户同步；封面一份文件，写一次之后不再改。盒的开合不存，从盒内 cable 的状态推出来。除 cable 自己那一份，没有第二个可变文件——59 的教训是共享可变文档最容易撞车（threads 整条线程当一条记录），新数据一律不做共享可变文档。

## 管线与秘书

35 的四相位（发现、粗筛、取材、分拣）原样不动，只是每一相位变成一个 legion run（55）。triage 的末端改掉：不再拼一份简报文档，而是每条 cable 出一页 brief 加一份优先级输入，投进盒子。36 的采集端选举挪进 `legion/presence`，claim 从「我是采集端」泛化成「这台设备能跑哪些 kind」。

**秘书长**三种模式共用一个游标：问答、主讲、语音。主讲是主持人拿麦，程序排序，用户随时可打断。

被打断追问：正文里答得上来的就地答；超出正文的转 tasking，即一个深挖 run，用 `idempotencyKey` 去重（写法同 55 的裁决 run），结果回来是一个新盒。秘书不编：正文里没有的就说没有，并提议开一个 tasking。

质量线五条：

1. 逐句可溯源。
2. 引文给原文，不转述。
3. 数字和日期由程序提取，不经模型转手。
4. 讲不寒暄。
5. 宁漏平庸，不推水。

随时可用不打扰：队列常备，从中断处接着听，不推送、不弹窗、不红点。锁屏播放与后台音频是必需项，不是加分项。

## 出口：稿

稿是给整块时间的产出，进书架。以下已定。

- 模型输出 markdown。app 内一个固定的 HTML 渲染壳（react-markdown 加已装的 gfm / math / katex / CJK 插件），不做模型写 HTML 那条路。
- 书架上的文件就是那份 markdown，不可变。再聚合出的是新文件；书架显示最新版，历史留着。划线按原文片段搬到新版，搬不过去的标出来。
- 没有页。竖滚，无页码无翻页。
- 引用指位置：稿是节（§3 加标题）加原文片段，PDF 是页加原文片段。一套语法两个头。
- `fulltext` 的 `pages` 数组实际是正文单元的下标，先不改名，补一段类型说明。所有提示词和文案里的「页」按文档类型改说「节」。
- 划线存法：节号 + 偏移 + 原文片段。Mark 概念不变。
- 图直接引源站 URL，不落本地。离线看不到图，接受。
- 来源列在稿末，用户自己复制 URL 去浏览器。app 内打开 cable 等以后。
- 交互块 v1 不做。将来做的形态是自定义 fenced 块对应组件。
- 已知风险：WKWebView 的系统选择菜单要压掉，否则划线手势和它打架。

v1 范围四块：书架条目加 kind（`LibraryEntry` 今天没有这个字段，`libraryPdfPath` 写死 `.pdf`）；HTML 渲染面板；markdown 抽取器（把 markdown 切成正文单元喂 fulltext）；文本锚划线。

「收藏的文章算不算书」单独讨论，不在这一场。

## 记忆回路与竞品

读：优先级输入读 concern 和 profile（48）。写：盒子里的动作写成观察，强度分三档——`dismissed` 弱、`asked` 中、`promoted` 强。`info-feedback.jsonl` 和 `info-profile.md` 并入这条回路，不再单独存在。cable 蒸馏之后由 `memory/gc` 按源登记表回收（58）。

竞品：约 45 个消费级产品加开源与学术侧全部核过。

全场没人做的八条：讲和稿从同一条管线出；聚合稿进阅读库、和保存的文章平起平坐、可划线可批注；音频的续播 + 可打断 + 锁屏三件齐；追问超出正文后转后台深挖、稍后回来交付；需求侧分「声明的视野」和「蒸出的 concern」两段且两段都可见可改；用户动作写回记忆并影响之后的排序；无服务器、数据在用户自己的云盘；数字和日期由程序提取。

没有优势、不投入的：定时摘要（大厂全有）、给文章配 TTS、双人对话播客、源的广度与媒体评级数据、授权正文（买版权这条路对我们关着）、通用取正文（Firecrawl / Jina Reader 是成熟商品）。

值得抄的：

| 抄什么 | 来自 |
|---|---|
| 每条故事固定骨架 Summary / Highlights / Key Quotes / Timeline / Context / Impact；源清单开源可提 PR | Kagi News |
| 固定条数、看完即止，末尾明说「今天到此为止」 | ChatGPT Pulse |
| 把系统对你的推断照给你看，做成一个独立面板 | Ground News（My News Bias）|
| 每条产出可点开看来自哪个源，且每个源可单独关 | Gemini Daily Brief |
| 音频答案带精确时间戳、可跳到那一秒 | Snipd |
| 收听中按住说话插嘴，主持人即刻响应并能承接反驳 | 腾讯新闻 AI 互动电台 |
| 每篇一张营养标签（clickbait 程度、主观性、来源数量、可读性） | Otherweb |
| 一句话交代盯什么，后台长期跑，有变化才回来 | Yutori Scouts |
| 冷启动先给一张跨域地图让用户圈范围，再拿打分当唯一训练信号 | Scholar Inbox |
| 粗筛不出二元通过，而是四维各给 0–10，结果可解释可纠错 | Obsidian Trending Digest |

最直接的对标是腾讯新闻 AI 互动电台（2026-05-13 上线，按住说话插嘴），其次是 Gemini Notebook 的 Interactive mode。撤退信号：Huxe 2026-05 停服且用户数据永久删除，Artifact 2024 关停，wiseflow 转型——单独做信息 agent 的都撤了，能活的都长在别的东西上面。
