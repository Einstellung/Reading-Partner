# 桌面自动更新

2026-09-18 定。macOS、Windows、Linux 的桌面版从 GitHub Releases 自己更新；手机走各自的商店和 TestFlight，不在这里。

## 什么时候更新

启动时查一次，之后每 6 小时查一次：桌面版开机自启、关窗进托盘，很少重启，只在启动时查会让大多数机器停在开机那天的版本。查到新版就在后台下载，下完在左侧栏 Settings 上方出一行「Restart to update」，悬停显示版本号。点了才安装并重启进新版；不弹窗，不催。查或下载失败只打日志，等下一次定时检查。阅读器里没有这个侧栏，回到首页才看得到。

安装等用户点，是因为 Linux 的 deb/rpm 安装要管理员密码（pkexec 弹框），而且安装期间 app 会退出。密码框点了取消，那一行会回来，下好的包还在，可以再点。

代码：`src/platform/app/update-policy.ts`（时间表和状态，有单测）、`updater.ts`（接 updater 和 process 两个插件）、`main.tsx` 启动、`AppSidebar` 画那一行。dev 构建和手机上整个不启动。

## 各平台装的是什么

`latest.json` 由 tauri-action 生成，每种安装包一个键：`linux-x86_64-deb`、`-rpm`、`-appimage`，`windows-x86_64-msi`、`-nsis`，`darwin-aarch64-app`、`darwin-x86_64-app`（都指向同一个 universal 包）。updater 先按自己当初的安装方式找对应的键，所以 deb 装的更新成 deb，rpm 装的更新成 rpm，AppImage 替换文件本身。Linux 三种格式都能更新，deb/rpm 要输密码。Windows 用 passive 模式，只显示进度条不要人点。

0.20.1 及以前的版本里没有 updater，第一个带 updater 的版本要手动装一次。

三个平台的 job 各自读改写同一份 `latest.json`，几乎同时结束时可能丢掉一个平台的键。发版后看一眼 `latest.json` 里七个键齐不齐。

## 签名和密钥

更新包用 updater 私钥签名，app 里内置公钥（`tauri.conf.json` 的 `plugins.updater.pubkey`），验签不过就不装。私钥在仓库 secret `TAURI_SIGNING_PRIVATE_KEY`，没有密码；备份在 Linux 开发机 `~/.tauri/reading-partner-updater.key`。这把钥匙丢了，已经装出去的客户端就再也收不到更新，只能让用户手动重装。

本地跑桌面 `tauri build` 也会签，要先 `export TAURI_SIGNING_PRIVATE_KEY=~/.tauri/reading-partner-updater.key`（可以是路径），否则打完包报 "A public key has been found, but no private key"。

macOS 包用 Developer ID 证书签名并公证。证书私钥在 Mac mini 的 `~/devid/`，导出的 p12 放在 secret `APPLE_CERTIFICATE`（base64）、`APPLE_CERTIFICATE_PASSWORD`，身份名在 `APPLE_SIGNING_IDENTITY`。公证用 iOS 那把 App Store Connect API key（`APPLE_API_ISSUER`、`APPLE_API_KEY_ID`、`APPLE_API_KEY_P8_BASE64`）。`APPLE_CERTIFICATE` 没配时 mac 包照旧不签名、不公证。
