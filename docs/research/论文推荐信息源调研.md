# 论文推荐信息源调研

2026-10-24。起因：想直接订阅别人已经筛好的 AI 和机器人论文来源，从里面挑着读，不自己搭筛选系统。范围是大模型、agent、具身智能、机器人操作（做饭机器人方向）。只交事实，不做取舍。

核实方法：WebFetch 抓各来源的归档页或 feed，看最近一期的实际日期；GitHub 数据用 `gh api` 取。微信公众号、X、Reddit、知乎抓不到，标"未核实"。以下"最近一期"都是 2026-10-24 当天抓到的。

## 摘要：订阅组合建议

- 每天：Hugging Face Daily Papers（https://huggingface.co/papers，可登录后订邮件日报；无官方 RSS，可用第三方 feed）；机器人方向再加 arXiv cs.RO 的 RSS（`https://rss.arxiv.org/rss/cs.RO`），或 GitHub 上的 Embodied-AI-Daily（按 VLA、世界模型、模仿学习等分栏的 arXiv 标题单，自动生成）。
- 每周：Import AI（周一，Jack Clark，偏研究解读）；机器人方向 RoboPapers（作者访谈论文，每周 1 到 2 期，有视频）和 Chris Paxton 的 It Can Think（机器人与 AI 长文，间隔 1 到 3 周）；The Batch（周五）作综合。
- 深入时：Ahead of AI（Sebastian Raschka，实现细节，近期约每月一篇）；Physical Intelligence 博客（pi.website/blog，VLA 一手工作）；GitHub 清单 BaiShuanghao/Awesome-Robotics-Manipulation 和 DravenALG/awesome-vla-wam（均在 10-22 更新）按子方向查漏；中文入门看 TianxingChen/Embodied-AI-Guide。
- 中文：量子位有 RSS，具身相关稿件多为产业报道；论文级中文解读的主力在微信公众号（具身智能之心、机器之心、新智元等），本次无法核实其质量和更新，需要程序读取要靠第三方公众号转 RSS 项目。

## 一、每日和每周论文精选

### Hugging Face Daily Papers

- 链接：https://huggingface.co/papers 。HF 官方，社区成员和作者提交，按点赞排序。页面有 Daily、Weekly、Monthly 三个视图，最新一日 10-23。
- 订阅：页面写明可登录后订阅每日邮件。没有官方 RSS。社区有两个非官方 feed：`https://papers.takara.ai/api/feed`（跳转到每日生成的 XML，10-23 那份 50 条，描述字段是完整摘要）和 jamesg.blog 的 hf-papers.xml（作者说明是抓页面，页面改版会坏）。来源：https://discuss.huggingface.co/t/hugging-face-daily-paper/142161
- API：`/api/daily_papers` 支持 `date`、`week`、`month`、`sort=trending`，无需认证，限额和字段见 [Hugging Face 作为检索与发现源调研](./Hugging%20Face%20作为检索与发现源调研.md)。
- 质量：每篇带 AI 摘要、GitHub 链接和星数、评论。条目偏大模型和视觉，机器人论文占比未统计。周末无日榜。
- Papers with Code 于 2025 年 7 月底关闭，原域名跳转到 HF Trending Papers，只保留热门论文与代码链接，原有排行榜不再从原地址提供。来源：https://juejin.cn/post/7537593417100492809 、https://www.codesota.com/papers-with-code 。第二手来源，关闭日期各家说法略有出入。

### arXiv 官方 listing

- RSS：`https://rss.arxiv.org/rss/<分类>` 或 `/atom/<分类>`，多分类用加号，如 `cs.ro+cs.ai`，上限 2000 条，每天美东午夜更新。来源：https://info.arxiv.org/help/rss.html 。`cs.RO` feed 实测可用，10-24 是周六，条目为 0。
- 邮件：向 `cs@arxiv.org` 发主题为 subscribe 的纯文本邮件，正文用 `add <子类>` 增减分类（页面示例是 q-fin 的 `add RM`，cs 下写 `add RO` 是照格式推的，未实测）。来源：https://info.arxiv.org/help/subscribe.html 。页面没写停用，实际是否仍发信未核实。
- API：export API 可按分类和日期查询，主题搜索那边实测会限流，见上面那份 HF 调研。
- 没有任何筛选。cs.RO 每天量大，只能当全量底座。

### alphaXiv

- https://www.alphaxiv.org 。论文页上有讨论，另提供 MCP server、Autoresearch、Chrome 扩展。Explore 页显示论文卡片和计数，未写计数含义和排序规则。App Store 页写有按社区阅读活动生成、每周刷新的 Trending Feed。来源：https://apps.apple.com/us/app/alphaxiv/id6782411985
- 未找到邮件日报或 RSS。官方博客最近一篇是 2026-09-09，主要是产品和训练实验文章：https://www.alphaxiv.org/blog

### Emergent Mind

- https://www.emergentmind.com 。自 2022 年起做热门 arXiv 论文、摘要和问答；有 API（页面标注 2025-09-04）和面向编码 agent 的 skill（2026 起）。页面未提 newsletter、RSS、价格。付费与否未核实。

### Semantic Scholar

- Research Feeds：把论文存进 Library 文件夹，打开该文件夹的 feed，第二天开始推荐；推荐器按你的 More/Less Like This 评分训练；邮件可选每日或每周。另有论文被引提醒和作者新论文提醒。来源：https://webflow.semanticscholar.org/faq/research-feed-alert 、https://webflow.semanticscholar.org/faq/email-alerts
- API：官方 api-docs 列有 Academic Graph、Recommendations、Datasets 三类。限额和是否需要 key 未在该页写明。

### Google Scholar alerts

- 三种提醒：查询有新结果、自己论文被引、某作者新论文。都只发邮件，无 RSS。来源：https://scholar.google.com/intl/en/scholar/help.html

### Connected Papers 等图谱工具

- Connected Papers 页面抓取只拿到标题，价格和免费额度未核实。它是以一篇论文为中心画相关论文图的工具，不是订阅源。ResearchRabbit、Litmaps 未查。

### Scholar Inbox

- 论文 arXiv 2504.08385 描述的个性化论文推荐平台（每用户一个逻辑回归，主动学习），机制摘要见 [AI信息筛选调研](./AI信息筛选调研.md)。官网 https://www.scholar-inbox.com 抓取无内容，价格、邮件、API 未核实。

### 其他自动聚合

- Paper Digest：每日爬 arXiv、medRxiv、PubMed 和会议，按影响力排序并写一句话摘要，有 Daily Digest 页。来源：https://www.paperdigest.org/daily-digest/ 。是否免费、更新是否仍在未核实。
- ArXiv Pulse、Arxivsub：个性化 arXiv 邮件摘要，均为小项目，更新状态未核实。
