# 机器人硬件学习资料

2026-10-24。读者是熟悉 TypeScript、Rust、Python 的软件开发者，硬件和机械近乎零基础，目标是能自己选型、搭一台桌面级机械臂（LeRobot SO-101 一类）并理解它为什么这样设计。本文是书和课程的有序清单加一条学习路径。

核实方式：书名、作者、年份、ISBN、中译本都在 2026-10-24 当天用网页检索和页面抓取核对。能打开的来源是豆瓣书目页（仅《现代机器人学》一本）、出版社页、图书馆目录、作者主页、GitHub 仓库页。只在检索摘要里见到、没打开原页的，在条目里标「摘要核实」；没核实上的标「未核实」，汇总在文末。价格不写。

## 摘要

软件人的入门顺序是先动手再补理论：第一周就买一套 SO-101，打印、装、校准、遥操作，用 LeRobot 录数据跑策略，这时看到的是总线舵机、供电和遥操作这一整条链。之后用《现代机器人学》（Modern Robotics）加 Coursera 课补运动学和动力学，用 MuJoCo 里的 SO-101 模型对着算。控制基础、电子和供电与前两步并行读。舵机的内部是黑盒，所以第二阶段打开黑盒：电机和 FOC（SimpleFOC、ODrive、moteus），再到减速和准直驱（MIT Mini Cheetah 一系），最后回到机械设计、传感器、力控，用一个自己选型的 QDD 关节收尾。

## 学习路径

条目编号见后面各类表格（B 书，C 课程，H 开源硬件，S 社区与博客）。「同时动手」一栏是该步旁边要做的实物。

1. 先把 SO-101 做出来（第 1-3 周）。读 H1 的 README 和 HF 装配文档、H2；C5 的 Robot Learning Tutorial 跑一遍遥操作、录数据、训练 ACT。对照读 S4（Dynamixel 手册）理解总线舵机怎么寻址、怎么设模式。同时动手：买 SO-101 套件或自己打印加买 STS3215；买万用表和可调直流电源。
2. 机器人学基础（第 2-8 周，与 1 重叠）。B1 第 2-8 章加 C1 视频，配套 Python 代码；H4 里的 SO-101 模型放进 MuJoCo 算正逆运动学和雅可比。中文读者用 B1 中译本。同时动手：用 B1 的代码对真实 SO-101 的关节读数算末端位置，和相机里看到的比。
3. 控制基础（与 2 并行）。B12 前半或 B13 加 C8（DR_CAN）：传递函数、PID、状态空间。同时动手：改 SO-101 舵机的 P/D 参数，看阶跃响应和负载下的抖动。
4. 电子与供电（第 4-8 周）。B11 选读（电阻电容、半导体、电机一章），需要深度时翻 B10；S5 学锂电池的化学、充放电和安全；ODrive、moteus 文档里的供电与制动章节讲电机电源的布线、保险、预充和制动能量。同时动手：用万用表和电源量 SO-101 的堵转和空载电流；做一块 ESP32 或 STM32 的小板（KiCad，见 S6）。
5. 电机与驱动，FOC（第 8-16 周）。B8 理解有刷、无刷、步进、舵机的区别和选型量（扭矩、转速、效率、温升）；C6（ST 电机控制 MOOC）和 H7 的 Theory corner 学 FOC；中文用 B15 和 H13。同时动手：一块 SimpleFOC Mini 加一个云台电机加磁编码器，先开环转，再闭环位置环、速度环、电流环。
6. 减速、传动与准直驱（第 14-22 周）。读 H9（Wensing 等 2017 的 proprioceptive actuator 论文和 Katz 的硕士论文）、H10（Dummy 里谐波加步进的做法和摆线减速器的仓库）。读 Harmonic Drive 的技术资料（未核实，见文末）补背隙和刚度。同时动手：用 H5（moteus）或 H6（ODrive）驱动一个 6:1 左右的行星减速关节，测背隙和反向驱动力矩。
7. 机械设计与 3D 打印（与 5、6 并行）。CAD 入门用 Onshape、Fusion 或 FreeCAD（入门资料未核实，见文末），拿 SO-101 的 STEP 文件读公差和紧固设计；这一类没有核实到可推荐的书，见文末。同时动手：给 SO-101 改一个夹爪或相机支架，打印两版对比公差。
8. 传感器与状态估计（第 18-26 周）。B5（Corke）的相机和视觉几章，B16（Labbe 的卡尔曼滤波）；磁编码器和电流感知在 H7、H5 的文档里。同时动手：给 SO-101 外加腕部相机和 IMU，做一次手眼标定。
9. 动力学、阻抗和力控（第 22-34 周）。B1 第 8-11 章，B2 或 B3 作对照参考；C4（Underactuated Robotics）选读摩擦、接触和优化控制；H9 的理论。同时动手：在 moteus 或 ODrive 关节上做电流环力矩控制、重力补偿和阻抗控制；Isaac Lab 或 MuJoCo 里做同一个控制器的仿真（H4、H12）。
10. 操作专题与学习型硬件，选型设计自己的臂（第 30 周起）。C3（Tedrake 的 Robotic Manipulation）、H3（ALOHA 系列三篇论文和硬件）、H2；ROS 2 作可选（C7）。同时动手：写一份自己的臂的选型表（关节扭矩、减速比、电机、驱动、供电、BOM），用 QDD 关节搭一个 3-4 自由度的臂。
