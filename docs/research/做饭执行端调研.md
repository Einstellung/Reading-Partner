# 做饭执行端调研

调研日期 2026-10-24。问题：信息端（食谱、三餐计划、做法页）已有，执行端用什么实体设备来做饭。范围是家庭厨房、中式家常（炒煮蒸炖）、在中国使用，兼看国际产品。只交事实和对比，不做取舍。

方法说明：检索工具对中文电商页和小众产品覆盖弱，部分页面只拿到搜索摘要而没有打开原文，这类条目标"摘要未核原文"。查不到的标"未核实"。人民币按 1 美元约 7.1 元、1 欧元约 8.3 元粗算，未核对当日汇率。

## 结论摘要

现状：能自己翻炒的家用设备已经量产（炒菜机、烹饪机器人，几千元），但备料、清洗、锅气三项仍是主要抱怨，且没有一款家用设备公开了让外部程序下指令的接口。

几条路线：

- 买国产炒菜机/烹饪机器人：国内渠道最全，价格几千元，能做炖煮和温和的炒，爆炒和清洗差；接口未见公开，只能通过厂商 App，米家系有社区集成但对该品类未核实。
- 买多功能料理机（Thermomix、Cookit）：可靠、国际口碑好，约 1.3 万元，能搅切煮蒸，不擅长中式爆炒；Thermomix 只有账号层面的 Home Assistant 集成，不能控制设备。
- 买海外整机（Posha 等）：Posha 约 1.1 万到 1.2 万元加月费，全程自动加料搅拌控温，但需自己切好料，强项是咖喱、炖煮、意面，不擅长高温煎炒，国内买不到（未核实）。
- 商用炒菜机器人：国内已大规模落地（每台约 1.8 万到 8 万元），按预设程序炒，无家用接口，面向餐厅。
- 用积木自己搭：电磁炉的程序化控制几乎没有现成产品；可买到的是联网电子秤、蓝牙探针（有 Home Assistant 集成）和热像模组（约 400 元）。备料、翻炒、出锅都得自己解决。
- DIY 机械臂：SO-101 一套约 1300 到 1700 元（国内 BOM），但开源模型和机械臂在炒菜类长任务上最好的公开数据是 Mobile ALOHA 炒虾 40%（5 次试验），离每天可用很远。

## 三、可编程的积木

### 3.1 灶具

- 米家电磁炉：2018 年台湾发布，可通过 App 远程查看火力和剩余时间；后续型号、国内现价、接入 Home Assistant：未核实。来源：https://www.ettoday.net/news/20181213/1330072.htm
- 涂鸦方案电磁炉：没有找到。
- DIY 改造：论坛有人用 PID 控制器接管电磁炉旋钮（旋钮电压 5V 到 0V），发现电磁炉最小功率 500W 是问题，未见解决结论；学术上有红外测锅温加 PI 控制调功率的论文。没有找到 ESPHome 现成项目。来源：https://www.electronics-lab.com/forums/goto/post?id=1624459 、https://zaguan.unizar.es/record/58534

### 3.2 秤、探针、摄像

- 联网电子秤：Home Assistant 官方 Acaia 集成（蓝牙，Lunar、Pyxis、Pearl 等），暴露重量、电量、流速、去皮/计时控制；同一时刻只能一个连接。来源：https://home-assistant.io/integrations/acaia 。国内价格未核实。

## 四、DIY 机器人路线

### 4.1 硬件与成本

- SO-101（LeRobot）：按官方 README 的 BOM，单个从动臂 $121.94 / ¥682.23，主从一对 $229.88 / ¥1,343.16；舵机 STS3215，7.4V 版堵转扭矩 16.5 kg·cm，12V 版 30 kg·cm；README 没有给负载数值（未核实）。成套散件在 eBay 约 $400。双臂移动机器人 XLeRobot 总价约 $660（README 引用）。来源：https://github.com/TheRobotStudio/SO-ARM100 、https://huggingface.co/docs/lerobot/en/so101
- Mobile ALOHA：整套 $32,000（含车载电源和算力）。来源：https://arxiv.org/abs/2401.02117

### 4.2 能做到什么

Mobile ALOHA 论文（CoRL 2024）每个任务约 50 条示教（炒虾 20 条），ACT 加与静态 ALOHA 数据联合训练，每任务评测 20 次，炒虾只评测 5 次：
- 炒虾：整任务 40%（不联合训练 20%）；分步：加油 100%、下虾 100%、翻面 60%、装碗 67%。失败集中在用锅铲翻虾和倒进白碗（与白桌子对比度低）。
- 其他：擦酒杯 95%、叫电梯 95%、开柜放锅 85%、冲锅 80%、推椅子 80%。
- 论文把炒虾低成功率归因于示教太少，未做更多验证。
来源：论文 PDF 表 1，https://arxiv.org/pdf/2401.02117

π0.5（Physical Intelligence）：在训练集之外的家里测试"碗放进水槽""收衣服""物品放抽屉""整理床铺""擦地"等，博客自己写"far from perfect"，目标是泛化到新场景而不是高灵巧新技能，页面没有做饭任务。来源：https://www.pi.website/blog/pi05 。openpi 仓库（Apache-2.0）含 π0、π0-FAST、π0.5，推理需要 8GB 以上显存，LoRA 微调需 22.5GB 以上，全量微调 70GB 以上；示例有 ALOHA 叠毛巾、从保鲜盒取出食物。来源：https://github.com/Physical-Intelligence/openpi

一个独立 SO-101 基准（arXiv 2606.08881，摘要未核原文）：每任务 20 次，SmolVLA 平均 32.5%，ACT 33.75%，π0.5 最高；Pen Transfer 任务上 π0.5 95%。

炒菜专项研究：Idiap/CUHK/武汉大学用人类示教训练双臂炒菜（structured-transformer）；2022 年 arXiv 论文把炒菜动作按阶段拆解；Georgia Tech 研究了颠锅的物理。来源：https://arxiv.org/pdf/2205.05960 、https://zmescience.com/science/news-science/science-wok-tossing-21112018 。这些均是实验室演示，未找到成功率或长期运行数据。

人形机器人：银河通用 Galbot G1 在世界机器人大会（2026）做了早餐流程演示，场景为模拟家居；新疆 2026-07-15 有人形机器人烹饪秀；CES 2026 有专做饭的 NOSH。均无成功率。来源：https://thestartv.com/v/humanoid-robot-cooking-show-turns-heads-in-xinjiang

### 4.3 离每天可用的差距

公开最好的炒虾数据是 40%，规模是一块虾、20 条示教、5 次试验。SO-101 是桌面小臂，负载未列，端热锅、翻锅铲未见公开演示。训练需要一块 24GB 级显卡（LoRA）。没有找到任何 DIY 方案连续运行几周做家常菜的报告。

## 五、安全

- 明火：电磁加热无明火，Posha、炒菜机、Cookit、美膳狮均为电磁加热；Matter 规范对非电磁炉灶具禁止远程关闭，说明规则对燃气灶更严。
- 标准：家电机器人安全的 IEC 60335-2-123 仍是草案（VDE 列表标 2026-06）；ISO 10218-1:2025 的适用范围排除家用消费品；个人护理机器人参考 ISO 13482；通用家电为 UL/IEC 60335-1。来源：https://www.vde-verlag.de/standards/1701976/e-din-iec-63682-vde-0700-123-2026-06.html 、https://www.iso.org/standard/18252.html 、https://tuv.com/landingpage/en/robotics/main/standards-and-services （标题和年份由摘要得出，编号未逐一核对原文）
- 产品层面：Posha、美膳狮、Moley、Flippy 的热油、刀具、防烫、断电、灭火机制：本次没有找到厂商公开的安全设计说明（美膳狮文章明确未提及）。Posha 厂商文章只提到部件可洗碗机洗，没有安全章节。
- Mobile ALOHA 论文没有关于热锅热油的安全措施说明。
- 刀具：现成产品里只有 Thermomix/Cookit 把刀封在锅内；其他备料环节都由人持刀。研究类开放资料里没有找到机器人持刀的家用方案。
