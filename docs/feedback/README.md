# 用户反馈

用户报上来的现象，一次反馈一个文件，文件名写具体的问题，收到的日期写在文件开头。每份记：用户看到了什么、代码里查到的原因、当场修了什么、留给统一设计的部分。不占编号。

- [电脑和手机的书不互通](./电脑和手机的书不互通.md) — Android 手机和桌面互相打不开对方导入的书，手机删不掉书，桌面更新到 0.22 后丢书
- [做饭计划一直 Thinking](./做饭计划一直Thinking.md) — 所有 soul 回合排一条队，停摆计时器在排队时过期，一个卡住的回合让全 app 停在 Thinking
- [辅助资料读不到](./辅助资料读不到.md) — 书的辅助资料里下好的论文，AI 读不到正文、搜不到、没有备课，只让读者自己去点开
