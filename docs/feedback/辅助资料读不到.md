# 辅助资料读不到

> 2026-09-29 收到。iPad，读《ZGCM-1 与 Plumb 双语读本》第 9 页，书级对话。

## 用户看到的

读到滑窗层的 sigmoid 门，报告只给了公式，出处是门控注意力论文 2505.06708。这篇论文已经下载进这本书的辅助资料，AI 却说读不到它的正文：搜了一次 "gated attention sigmoid gate attention sink"，结果全是 ZGCM-1 本身；让用户去 Outline 点开论文、在那边开对话，它才能读。备课也没有覆盖这篇。

## 原因

- 辅助资料摄入时一定会抽全文，按文档 id 存进 fulltext store。但 AI 读它只有 `read_paper` 一条路，而 `read_paper` 只在书有论文型备课管线时才挂，只认登记进那条管线的条目（`reading/desk.ts`）。ZGCM-1 是书级报告，走章节型备课，没有论文管线，所以论文进了库，AI 却够不着，也没有备课笔记。
- `search_topic` 只搜 topic 书架上的书，不含辅助资料。
- prompt 明写辅助资料「由读者从 Outline 打开，不由模型读取」。AI 让用户去点开，是照这句说的。点开后 `read_pages` 读屏幕上那份，所以点开了才读得到。
- 顺带发现：读者正看着辅助资料时，topic 材料里「当前这本书」的全文和划线用的是屏幕上那份辅助资料的，`search_topic` 会把辅助资料的页标成书的页。

## 当场修了的

分支 `fix/supplement-reach`：

- 新工具 `read_supplement(title, from, to)`，每个书内线程都挂，按标题从 fulltext store 读，页头带 `[标题 p.N]`（`reading/ingest/read-supplement-tool.ts`）。
- `search_topic` 的范围加上这本书的辅助资料（`reading/context.ts`、`reading/desk.ts`）。
- prompt 改成辅助资料 AI 自己能读，不再让读者先点开。
- 看着辅助资料时，书本身的全文和划线从 store 读，不再借用屏幕上那份。

## 留给统一设计的

辅助资料现在是「挂在书上、给读者看的文档」，备课是「按书的形态二选一的管线」，两者没对齐。要重新设计的：

- 备课覆盖辅助资料。现在只有论文型书的管线会给它做笔记；章节型书的辅助资料没有笔记，`read_note` 用不上。是每进来一份就自动备课，还是在对话里第一次被问到时再读。
- 归属范围。辅助资料只挂这本书，同 topic 其他书搜不到。同一篇论文（比如这篇门控）读别的模型报告时也会用到。
- `read_paper` 和 `read_supplement` 两条读路并存：论文型书里被管线登记的辅助资料两个工具都能读。长期应该收成一条。
- 读者看着辅助资料时，`read_pages` 读的是辅助资料，书本身的页读不到；书级线程里「屏幕上是哪份」和「这本书」要分清。
