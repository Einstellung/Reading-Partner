# 不加过滤的 `idevicesyslog` 会把你的日志丢掉

## 现象

`idevicesyslog -u <udid> > /tmp/x.log` 跑四分钟，文件 127MB，里面自己 app 的
`NSLog` 只有 **13 行**。同样的代码在别的轮次里同样时长能出几百行。

按这个日志判断"我的 NSLog 没打出来"，就会去追一个不存在的 bug。

## 原因

设备的系统日志本身就有约 0.5MB/s，全量往下拉再写盘，中继跟不上就丢。丢的是哪一段
不挑，你自己的行没有优先级。

## 解法

在中继侧就过滤，别自己 grep 落盘的文件：

```
idevicesyslog -u "$UDID" -m RP-DICT > /tmp/rp-dict.log
```

`-m/--match` 只输出含指定字符串的消息，`-p/--process` 按进程过滤。加上之后同样时长的
日志几十 KB，一行不丢。

判据是"行数对不对"，不是"文件大不大"——127MB 的日志看着像什么都记下来了。
