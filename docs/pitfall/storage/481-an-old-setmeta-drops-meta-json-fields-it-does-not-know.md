# 老版本写 meta.json 时丢掉它不认识的字段

## 现象

给 `observations/meta.json` 加的新字段（`distilledMessageKeys`），只要一台还在老版本的设备跑过一次 pass，就从文件里整个消失；同一映射里值不是数字的条目也一样。

## 原因

`ObservationFileStore.readStoredMeta` 只解析它认识的四个映射，每个都过 `numberMap`（非数字的值扔掉）；`setMeta` 读出这四个映射、改完、整份重写。不认识的键和非数字的值在读的那一步就没了。同步合并时，老设备这次写入对新字段来说是「删除」，本地没改过的那部分就跟着删掉。

## 解法

新信息放新字段，不改旧字段的类型：旧字段照写，老版本照常用；新代码读的时候不假设新字段一定在，缺了就按旧字段的老意思读。要是把新表示塞进 `distilledMessages` 的值里，老设备读到的是空映射，会把整个主题的对话从零重蒸一遍。往 meta.json 再加字段同理。
