# 权限生成器不删陈旧文件，漏登记的命令靠一份旧 toml 活着

## 现象

`plugins/voice/build.rs` 的 `COMMANDS` 里没有 `release_microphone`，
`permissions/default.toml` 里却写着 `allow-release-microphone`，而这个命令
在真机上一直正常工作。按理说 ACL 找不到这条权限就该在到 Rust 之前拒掉。

## 原因

`tauri_plugin::Builder` 把每条命令生成成
`permissions/autogenerated/commands/<name>.toml`，写进源码树而不是 `OUT_DIR`。
它只写不删：`release_microphone` 曾经在 `COMMANDS` 里，生成过一次
`release_microphone.toml`，后来从 `COMMANDS` 里掉了，那个文件还留在树里、还
被提交着，ACL 照样读得到。

于是漏登记不报错，一直到有人清空 `autogenerated/` 重新生成——那时候命令会毫无
征兆地被拒掉，而 `build.rs` 和 `default.toml` 看起来都没动过。

## 解法

`default.toml` 里的每条 `allow-*` 都要在 `build.rs` 的 `COMMANDS` 里有对应的
一行，两边对着看一遍。改了 `COMMANDS` 就把 `permissions/autogenerated/` 一起
重新生成并提交；`git status` 里出现没预期的新 toml，说明之前漏登记过。
