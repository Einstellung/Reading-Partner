# 206 `xcodebuild` 的输出缓冲到构建结束才吐出来

## 现象

`xcodebuild ... | tail -n 20` 在整个构建期间一行都不打印，直到构建结束才一次性吐出来。想边跑边看进度，看不到。

## 原因

接了管道之后 xcodebuild 的输出不是行缓冲，整份日志攒在缓冲区里，构建跑多久就等多久看不到任何进展，和构建本身快慢无关。

## 解法

重定向到文件，另开一个 `tail -f` 盯着文件，两条分开跑。`scripts/ios-swiftcheck.sh` 是 `xcodebuild ... build >"$log" 2>&1`，构建结束后再从文件里取诊断；要看实时进度单独 `tail -f "$log"`。
