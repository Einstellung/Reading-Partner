# 中文期刊 PDF 每页铺一张整页位图水印，两条图形检测都被带偏

现象：软件学报的 PDF 走版面分析，两条找图的路都出错。按 `getOperatorList` 的图像绘制操作定位图形，整页被当成一张图，该页所有文本被吞掉，23 页抽出 0 个字符。改成渲染后按「有墨但没有文本覆盖」找矢量图形，灰度阈值定在 232 时，23 页切出 63 张「图」，全是碎片。

原因：这份 PDF 每页有一张覆盖整页的图像对象（`paintImageXObject`，包围盒等于页面框），画的是淡灰的 `www.jos.org.cn` 斜向水印。它对第一条检测是一张合法的整页图，对第二条检测是一片浅到刚好过阈值的墨。

解法：两条一起上。图形区域面积超过页面 62% 的丢掉，区域内含有超过 45% 页面文本项的丢掉；墨阈值从 232 压到 200。
