# 饮食忌口存进档案了，计划里照样有

## 现象

三餐对话里说「我不吃西兰花」，卢明回说改好了，计划里还是有西兰花。没真模型的测试复现：档案里写进「西兰花」或「broccoli」后，139 道种子菜一道都没被挡；草稿卡和存盘的计划原样不动，`update_meals_profile` 回模型的是「Saved. Daily targets now … Say it in one line」，存盘计划那边还多一句「The week's grams are re-solved」。

## 原因

两处叠在一起。

- `foodAllowed` 只按 id、完整中文名和别名一对一地比，「西兰花」只挡住鲜西兰花那一行。种子菜用的全是 `frozen_broccoli`（冷冻西兰花），所以什么都没挡；英文名「broccoli」也不认。对不上任何食物的词照样存进档案，没人提示。
- `update_meals_profile` 只存档案、重解克数，不碰还没确认的草稿卡；存盘计划的草稿被新忌口打掉一道菜时保持原样。结果里只有「已保存」和「重解了」，没有一句说卡和计划没变，模型就说成改好了。

## 解法

`foodsNamed` 按 id、中文名、别名、英文名认，一个名字对上的行全算，鲜品和冻品按中文名前缀「冷冻」「冻」配对后算一样；对不上任何食物也不是标签的新忌口不存，结果里点名。忌口只在某种吃法的现配菜里时只挡这种吃法（`lib.wayBlocked`）。改档案后程序拿新档案查卡和存盘计划，有被拒的就从模型当初的选择重补（`planner/redraft.ts`），补得过就原地换卡、重写计划；结果逐顿写改了什么、哪几顿还有，告诉模型结果里没写改了的不许说改了。测试在 `tests/info/meals/dislike-applied.test.ts`。
