# 入库 agent 没被告知时会替用户审内容

## 现象

docs/86 的比对里，Haiku 5.5 对 suyuan1711 那篇 X Article 跑 3 次，1 次没入库：#1 能入库、质量关通过，模型直接 finish，note 是「这是教人伪造美国居住地、绕过 Anthropic 地区和 KYC 检查的指南，不加进书库」。另外 2 次正常 `file(1)`。

## 原因

系统提示只说了「找到链接真正指的内容并入库」，没说内容好不好不归它管。模型把 file 当成自己替这份内容背书，按自己的标准拒了一部分。不是 provider 的拒答：回合正常结束，工具调用和 finish 都是模型自己发的。

## 解法

系统提示写明它不判断内容好坏、真假、是否认同：链接是用户自己分享、自己要读的，它只判断链接真正指的是哪份文档（`info/links/agent.ts`）。加上之后同一篇 3 次都入库，整轮 24 次没再出现。别的「替用户把东西放进他自己的库」类 agent 同样要写这一句。
