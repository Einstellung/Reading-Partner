# 语言设成 auto 时，简报书和开场话每次自己挑语言

## 现象

2026-10-15 主题搜索第一次真跑（日常档 GPT-6.1-sol，语言设置 auto），材料几乎全是英文论文。两次构建：一次结论句、正文、全景和卢明开场话都是英文；另一次全是中文，夹着程序写的英文标签（「Not yet known.」「Original:」「Notes」「Contents」）和英文的原文标题。冒烟那次构建出英文书，开场话也是英文；真跑那次书是中文，开场话中文。同一期里书和开场话也可能不一致：开场话的提示里没有读者画像，独立挑一次。

## 原因

`languageInstruction("auto")` 返回空串，提示里没有语言指令。别的 auto 场景靠「跟着用户说的话走」，结果构建（`topic-search/compose.ts`）的提示里只有材料和读者画像，画像中英混写，模型按次数随机落在一边；开场话（`issue/opening-record.ts`）的提示里只有条目，没有一句读者的话。

## 解法

开场话在 auto 时补一句「Write in the language the items below are written in.」，跟这一期书走，同一期里不再分家。书本身在 auto 下用什么语言没定：程序写的标签是英文，画像是中英混写，要定一个（界面语言，或英文），由主会话和用户定了再改 `compose.ts` 的提示。其他只拿材料、没有读者原话的 auto 提示有同样的空子。
