# `arxiv.org/html/<id>` 没有 HTML 版时可能返回 200

现象：判一篇论文有没有 arXiv 官方 HTML 版，按 HTTP 状态码判会把一部分「没有」当成「有」。两种失败形态混在一起。一种是 404，body 是 1208 字节的 arXiv 错误页，好判。另一种是 200，body 是约 20 KB 的壳，`<title>Untitled Document</title>`，去标签后正文只有三千多字符，页面上写着转换不可用。1412.6980v9（Adam）就是第二种。

原因：arXiv 的 LaTeXML 转换失败或没跑过的论文，有的路由到错误页，有的路由到一个空壳文档，后者是正常返回的一份 HTML。带版本号和不带版本号返回的字节数完全一致，也区分不出来。

解法：判存在要看正文长度加 title，不看状态码。实测用的判据是 HTTP 200、去标签后正文超过 8000 字符、`<title>` 不是 `Untitled Document`，40 篇抽样上没有误判。
