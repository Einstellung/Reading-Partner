# 手机横过来弹软键盘，只剩 168px

## 现象

iPhone 横屏点对话输入框，软键盘加附件栏之后能看见的只有一条缝，输入框一截压在附件栏底下，一行对话都看不到。三个对话面都一样。

实测（iPhone 17 Pro Max 横屏，iOS 26 模拟器，440 高）：visual viewport 168。输入框的 top/bottom（从可见区域顶端量）：

| 对话面 | 顶上占掉的（按类名推算） | 输入框 top/bottom（实测） |
|---|---|---|
| 简报对话 | 列表的 `pt-36` 144 | 144 / 206 |
| EPUB 课堂 | 返回行 53 + 章节行 45 + 列表顶距 16 | 114 / 176 |
| PDF 课堂 | 返回行 53 + 列表顶距 16 + 两颗快捷钮 52 | 121 / 183 |

## 原因

外壳按坑 443 挪到可见区域顶端、`CallView` 垫掉被盖住的高度之后，对话只剩 168 高。列表是 `min-h-0` 能缩到 0，但它的 padding 缩不掉，顶栏和输入框也缩不掉，加起来就超过 168，超出去的那截落在键盘底下。

## 解法

可见高度低于「最高的顶栏 98 + 最高的输入框行 122 + 两行对话 72 = 292」时，`keyboardFrame` 给出 `cramped`（`common/keyboard-frame.ts` 的 `chatBarFits`），外壳经 context 交给 `CallView`，它把宿主的顶栏、角上的挂断/删除、章节行都收起来，列表顶距回到 16。竖屏软键盘剩 543、硬件键盘附件栏剩得更多，都在线上面，竖屏不变。
