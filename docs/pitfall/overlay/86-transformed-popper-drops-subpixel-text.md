# 浮层里的字换成灰度抗锯齿，逐像素对比整片飘红

## 现象

新旧两份产物的下拉菜单截图逐像素比：4308 个像素不同，最大差 129，每一行文字都在差异图上发亮。可几何和计算样式逐条相同，肉眼看两张图一模一样。

## 原因

Radix 的 popper 用 `transform: translate(x, y)` 放置浮层，这让它成为独立合成层，Chromium 在合成层上关掉次像素（LCD）抗锯齿改用灰度。同一个字形、同一个位置，边缘像素从带色边（`(133, 204, 242)`）变成灰阶（`(212, 212, 212)`）。

平移量是整数，不是次像素定位问题。

## 解法

比较时两边都关掉：Chromium 启动加 `--disable-lcd-text`。同一组截图重比，差异只剩真正改了颜色的那一行（4308 → 2334，其中 1685 个是差 1 的合成舍入，超过 20 的只有 18 个）。

不用去掉那个 transform——它是浮层定位本身。iOS 上 Retina 屏本来就是灰度抗锯齿，这个差别在目标设备上不存在。
