# 653 删掉「读音和单字默认一样」的 pypinyin 词组会改读音

## 现象

给 Kokoro 文本前端（`plugins/voice/src/kokoro_g2p`）导 pypinyin 词组表时，把首读音与逐字默认读音完全相同的词组删掉，41 万条剩 3.6 万条。拿 jieba 词表全部词条对比删前删后的 `lazy_pinyin`，有 6813 个词读音变了。

## 原因

pypinyin 先用词组表做正向最大匹配（`mmseg`）切分，再按切出的片段查读音。词组表同时是前缀集合：删掉一个「读音无所谓」的长词组，会让匹配在更短处停下，或让它的前缀链断掉，于是后面的字被切进另一个读音不同的词组。词组本身的读音无所谓，它在切分里的位置有所谓。

## 解法

`tools/kokoro_g2p/export_data.py` 删完之后对 jieba 全部词条模拟删前删后的 mmseg，把删前切分用到、而读音变了的词组放回去，迭代到不再收敛为止（第二轮起整词内的所有词组都放回）。最后保留 42360 条，还有 7 个 jieba 词条因为更长词组的前缀链读音不同，接受。表要再裁，必须重跑这一遍对比，不能按「读音和默认一样」直接删。
