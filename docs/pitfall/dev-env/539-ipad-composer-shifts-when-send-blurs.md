# iPad 模拟器上按完发送立刻点停止会落空

## 现象

iPad 模拟器上，回合在流时 idb 点发送插一句话，100 到 300 ms 后点停止：插话进了同一回合，回合照常跑完，停止没生效。同样的流程隔 1.5 s 再点停止，或者发送后立刻用 JS 对停止按钮 `click()`，都按设计停下（半句留下，被撤回的插话开下一回合）。

## 原因

模拟器接着硬件键盘，输入框聚焦时屏幕底部出快捷栏，整个输入条上移约 35 pt（Send 从 y=1135 到 1100）；发送后输入框失焦，快捷栏收起，输入条落回去。发送前量到的停止坐标、或者发送后马上量到的坐标，都可能落在动画中途的空白处。

## 解法

验「插话后同一刻停止」时，发送后用页面 JS 点停止按钮，或者等输入条落定（约 1 s）再用 idb 点重新量出的坐标。只用 idb 点、隔几百毫秒的结果不能算停止失效。
