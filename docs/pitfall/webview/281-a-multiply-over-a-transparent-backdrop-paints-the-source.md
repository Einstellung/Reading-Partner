# 281 隔离组里的 multiply，背后是透明就直接画出乘数色

## 现象

EPUB 页卡片的白纸画在宿主 `.rp-page` 上，在 shadow root 外面，也在混合组外面；组里只有版心和 `.rp-wash` 两层。按「乘法总得有东西可乘」推，页边距那一圈应该还是白的。实测整张纸是 `#f6efdc`，和旁边那页 PDF 逐像素相同。

## 原因

`isolation: isolate` 之后组内的背景是透明的。CSS 合成的公式是 `(1 - αb)·Cs + αb·B(Cb, Cs)`：αb 为 0 时结果就是源色 Cs。所以 wash 盖在组里没人画过的地方直接画出 `--page-wash` 本身，整组再照常合成到宿主的白纸上。

## 解法

组里放什么只按「谁该被乘」决定，不必为了给 multiply 垫底把纸也搬进组。反过来，也别把「组里还没画东西」当成 wash 是 no-op：那一片会是纯粹的乘数色。真正的 no-op 判据在源色那边——`var(--page-wash, transparent)`，透明源乘什么都是原样。
