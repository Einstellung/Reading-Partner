# 配色

2026-09-06，0.13。整套颜色从「纯白 + 紫」换成「纸 + 苔绿」。改的是 `styles.css` 里的 token 取值，组件里原来写死的十六进制全部换成对应 token 的 utility class。

## token

| token | 值 | 角色 |
|---|---|---|
| `--background` | `#faf9f6` | 页面底色 |
| `--card` / `--popover` | `#fffefa` | 卡片和浮层，比页面亮一档 |
| `--foreground` / `--card-foreground` / `--popover-foreground` | `#252922` | 正文墨色 |
| `--muted-foreground` | `#5c6058` | 次级正文：卡片副标题、字段说明、列表行正文 |
| `--faint-foreground` | `#6f726a` | 元信息：时间、计数、来源标签、placeholder |
| `--muted` / `--accent` | `#efefe8` | 常规灰底 |
| `--muted-faint` | `#f3f3ed` | 最浅一层：侧栏底、行 hover |
| `--muted-soft` | `#f1f1ea` | 要读成一个形状的底：状态 chip、占位块 |
| `--muted-strong` | `#e3e3db` | 按下态 |
| `--border` / `--input` | `#e5e5dd` | 常规线 |
| `--border-soft` | `#ebebe3` | 卡片外框 |
| `--border-subtle` | `#f0f0e9` | 分区线、吸顶栏下沿 |
| `--border-faint` | `#f6f6f0` | 密集列表的行间线 |
| `--primary` | `#52664e` | 主色 |
| `--primary-foreground` | `#fffefa` | 主色上的字 |
| `--primary-hover` | `#435441` | 主色按钮 hover（变深，不是变浅） |
| `--secondary` | `#e6e8db` | 二级 chip 底 |
| `--secondary-faint` | `#f2f4ec` | 整张卡属于主色时的底，`--secondary` 会把卡画成 chip |
| `--secondary-foreground` | `#3f5039` | 二级 chip 上的字 |
| `--secondary-border` | `#c9cfbd` | 二级 chip 的线 |
| `--secondary-hover` | `#dde0cf` | 二级 chip hover |
| `--ring` | `#52664e` | 焦点圈，跟 `--primary` |
| `--chat-surface` / `--chat-code` / `--chat-bubble` | `#f6f5f0` / `#f2f1ea` / `#ebeae2` | 聊天窗口那三层，从上到下越来越深 |

`--faint-foreground` 是这次新加的一级，替掉各处写死的 `#777`…`#bbb`。它在 `#faf9f6` 上是 4.65:1，正文字号的下限就是这个，不许再浅。定稿时写的 `#787b73` 只有 4.09:1，按 4.5:1 往下压了一档。

灰底和线各自是一条从浅到深的梯子（`muted-faint` → `muted-soft` → `muted` → `muted-strong`，`border-faint` → `border-subtle` → `border-soft` → `border`），顺序由 `tests/ui/components/paper-tint-contract.test.ts` 盯着，换值不能换序。

## 显示字体

`--font-display: Georgia, "Noto Serif SC", "Songti SC", "Source Han Serif SC", serif`，用 `font-display` 这个 utility。不引 webfont 也不加 `<link>`：iOS 自带 Georgia 和宋体，而字体栈里第一个解不出的 family 每个文档都要付一次钱（坑 178）。

只给「说清楚读者正在看什么」的那几个标题：Today 标题、续读卡的书名、topic 卡上的 topic 名和 topic 页的标题、简报页的总述句和条目标题、文章页的标题，以及手机形态里对应的那几个。正文、聊天、设置、阅读页都不用。

## 不动的

状态色照旧写在调用点：错误的红、同步提醒和「out of your lane」的琥珀、源健康点的绿。它们表达的是含义不是身份。PDF 上的标注颜色（`platform/app/annotations.ts`）是内容，同样不动。`base/icons.tsx` 里那三个色是 app 图标自己的配色，跟着图标走。

## 纸色开关

默认底色本来就不是纯白了，所以设置里那个开关不再是「白变米」，而是在新梯子上整体再暖一档：底 `#f6f1e4`，卡 `#fbf7ec`，灰底和线各自跟着走一步，绿色和文字色不动。`--page-wash` 和阅读页那层 multiply 没变。

## 范围

阅读页、聊天、markdown 渲染、设置这半边在同一个版本里一起换，是另一条改动线。
