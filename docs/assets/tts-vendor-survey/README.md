三个维度加一份排名稿的原始输出，机械转写自 JSON，措辞未改。2026-08-27 跑。结论已吸收进 [46](../../46-TTS供应商横评.md)，实测发现结论不对时回来查这里。

每份的 Fact-check 一节是核查阶段的结果：verdict 为 corrected 或 refuted 的条目推翻或修正了同一份里的原始值，以那一节为准——但有四条例外，列在下面。

## 最终推荐已作废

`ranking.md` 第 2 节的结论是「不要换，留在硅基流动」。这条作废。它成稿时音质那一轮还没出结果，输入里硅基流动仍是「首帧 0.9%、RTF 0.118、p90 350.9 ms 全过」的现状；它不知道硅基流动实测出来是 16 kHz 上采样冒充 24 kHz、31 句里 11 句随机内容损坏。实测结论以 [33](../../33-语音简报.md) 为准。

仍然有效的是三样：候选清单、价格口径、质量证据。

## 核查本身出错的四条

**三条把硅基流动单价改错了。** `round-02` 的 refuted 条目改成「¥0.05 / 1000 UTF-8 字符」得出 ¥0.0100/min，`round-03` 的 corrected 条目改成「¥0.05 / 百万字节」得出 ¥0.0000299/min，还有一条按前者重算了全表的倍数关系。三条都不对。定价页原始数据是 `{"price":"50","specification":"utf8_bytes","unitOfGood":"/ M UTF-8 bytes"}`，页面显示「¥0.05 / 千字符 UTF-8」，两个数只有在单位是**字节**时才自洽，API 文档也写明按 UTF-8 字节计费。正确口径 ¥0.05 / 1000 UTF-8 字节 = ¥0.0299/min（199 汉字，不含标点）。`ranking.md` 已经逐条驳回了这三条，46 按 ranking 写。

**一条把讯飞的价格判成「公开可查」。** `round-01` 的 refuted 条目给出 ¥1.20–2.00/万字符。那是 `xfyun.cn/services/smart-tts` 里**在线语音合成**（老一代）的价格，不是超拟人的。超拟人产品页返回未找到页面，单价至今没有公开数字。

## 跑完之后又改掉的两条

来自对官方计费页的逐字复核，晚于本目录里的所有内容：

- **阿里其它 TTS 模型的价格是公开的**，不是排名稿写的「未公开」。同页明写 1 汉字 = 2 字符：cosyvoice-v3-plus ¥2/万字符（¥0.0796/min）、qwen-audio-3.0-tts-plus ¥1.4（¥0.0557）、qwen-audio-3.0-tts-flash ¥1（¥0.0398）、qwen3-tts-flash ¥0.8（¥0.0318）。来源 https://help.aliyun.com/zh/model-studio/billing-for-model-studio
- **腾讯不是「没有 24k」**。官方文档写「24000：24k（部分音色支持）」，24 kHz 存在，只是不是所有音色都支持；接口要求表和 SampleRate 参数表在同一页上口径不一致。来源 https://cloud.tencent.com/document/product/1073/94308

## 其它读的时候要知道的

- 火山那个「2 万字符 / 半年」的免费试用额度无法在公开文档页核实，只查到通用说法「首次开启默认为试用版本…一定的免费额度」，具体数字在控制台里。
- 所有 ¥/min 按 199 汉字/分钟折算。实测语速是 193.8–197.8 汉字/分钟，所以这些数系统性偏高 2–3%，不影响厂商间的相对排序。
- 火山的价格与质量数据经逐字复核无误：0.879、CI [.857, .898]、coverage .913 以及分类失分与论文 Table 5、Table 7 精确匹配。基准论文本身核实为真实存在、七个系统名单精确无误。
