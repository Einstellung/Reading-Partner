# 聊天里画结构图

> 上游是 [12](./12-图片讲解.md)（AI 拿着论文的图讲）和 [09](./09-学习机模式.md)（classroom）。[32](./32-思维导图调研.md) 已经把「引库画图」这条路走过一遍，结论在下面直接用。

## 动机

classroom 里让 AI 讲书里的图，它现在只能 `[fig:N]` 引原图再配一段文字。密集的架构图配文字用户看不懂——用户要的不是描述，是**重画**：把此刻在讲的那条路径单独画出来，或者分步骤逐层叠加。

## 不走图像生成

扩散模型照着架构图重画一个标签正确的简化版做不到：图里的文字会变成错别字（中文尤其），而且不可控——说「把 QKV 那条线单独画出来」整张图会全变。图像生成留给具象插画，是以后另一条分支，接进来时只是 `reading/diagrams/prompt.ts` 那个判据阶梯多一级。

## 也不让模型自由写 SVG

它会画重叠错位。模型只描述**结构**，版面由渲染层算。模型写不出坐标，所以画不出两个叠在一起的框。

## DSL

`src/reading/diagrams/types.ts`。一个 `nodes` + `edges` 的图，加四种布局、分组、标注，再加两个**视图**：

- `focus` —— 点亮一条路径，其余淡化。`focus.path` 给节点序列，中间的边自己解析（正反向都认，读者顺着「Q 是哪来的」倒着走是常态）。这是「我还是没懂，把那条线单独画出来」的正解。
- `stages` —— 同一结构分步展开，累积式；本步还没引入的元素画成极淡的幽灵，位置先占着。

布局**永远看整张图**，`focus` 和 `stages` 只改每个元素的 `emphasis`。所以翻步骤、切高亮的时候框一动不动，读者看的始终是同一张图在变，而不是一张接一张要重新读的新图。这条由 `tests/reading/diagrams/layout.test.ts` 的「stepping through the stages never moves anything」钉着——它没了这个功能就没了，别的测试全绿也没用。

四种布局，各是一套算法：`flow`（分层有向图，主力）、`stack`（横带，一个 group 一条带；跨带的边走侧边导轨，残差连接就是这么画的）、`sequence`（生命线 + 按 `edges` 数组顺序排的消息）、`tree`（层级）。

## 渲染：手写 SVG + 自己算布局

[32](./32-思维导图调研.md) 已经查过：mermaid 解包 83MB，且它做不到这里最要紧的两件事——稳定几何的分步展开，和路径高亮淡化。所以不引库，零新依赖，天然离线，iOS webview 里就是普通 SVG。

文字宽度按字符估。`src/reading/diagrams/text.ts` 用 Helvetica/Arial 的真实字宽表（Liberation Sans 完全一致，栈里其余字体都不更宽），CJK 一律 1em，再乘 1.04 余量。方向是**只许估宽不许估窄**：估宽了框松一点，估窄了字戳出框外，后者是这套做法唯一不能有的失败。这张表拿 Chrome 的 `measureText` 在中英日韩混排语料上校准过，结果连同测量值一起钉在 `tests/reading/diagrams/text.test.ts` 里。

几何和画法分开：`layout.ts` 出 `Scene`（纯坐标），`svg.ts` 出一棵 `SvgNode` 平铺数据树，两个薄发射器——`serializeSvg` 出独立 SVG 文件（测试、离线核对、以后进 deck），`SvgFigure.tsx` 出 React 元素。一份几何、一份元素树，两个翻译器，不会漂。

## 工具与判据

`draw_diagram` 和 `update_diagram`（`src/reading/diagrams/tools.ts`），只在 classroom 且宿主有聊天行可放卡片时挂。

`update_diagram` 不是顺手加的：读者说「还是没懂」时，再发一张图等于让他自己去 diff 两张图；在他正看的那张上点亮一条路径、或者拆成步骤，才是答案。工具描述和提示词都明写不许为同一件事画第二张。

模型的每次输出都过 `normalize.ts`：能修的修，修不了的丢，**每一处改动都写回工具结果**。不告诉模型它那条边被丢了，它下次还画同样的断边。

什么时候值得画一张图，判据只写在 `prompt.ts` 一处，和图目录一起出：先看书里有没有现成的图（`[fig:N]`），没有再看讲的是不是结构关系，是就画，不是就别画（定义、比较、清单用文字或表格更快）。分开写会漂——模型在图目录旁被告知「引图」、在画图工具旁被告知「画图」，同一个点上两件都做。`buildFigureCatalog` 原来那句半条判据的 heading 因此可以被覆盖。

## 持久化

存 DSL，不存渲染结果——几百字节的结构，重开时重新排版。图是它周围那段讲解的一部分，重开发现文字指着一张不在了的图，比没画还糟。`stage` 也存：读者走到第三步，明天回来该还在第三步，而不是倒回第一帧。

`use-call.ts` 里**唯一的**diagram 存放处就是 thread 文件，每次读都回去读它。这样两件事才成立：`update_diagram` 在**下一个**回合生效（「还是没懂」永远是下一回合才来的），以及重启后重开 thread 卡片还带着同一个 id。

## 只有真机能验的

iOS WKWebView 里内联 SVG 的字体回退（估宽表按 Helvetica 校准，SF Pro 更窄，方向安全，但没在真机上量过）；触摸上分步按钮的手感；长图在手机聊天列里横滑的体验。
