# 聊天里画结构图

> 作废 2026-08-20：整个功能已删除。`src/reading/diagrams/`、`draw_diagram`／`update_diagram`、diagram card part 和它们的测试全部删掉，不留开关。
>
> 原因：DSL 画出来的是代码前向过程的转录（W_query/W_key/W_value → view+transpose → Q·K → 掩码 → softmax → dropout），每条边的含义都是「然后」，讲不出概念。需要的是公式和概念引导。这套 DSL 曾靠「布局永远看整张图，focus/stages 只改 emphasis」保证分步展开时框不动、读者看的始终是同一张图在变——但判据阶梯本身站不住，这条工程上的正确性就跟着一起废了。
>
> 替代方向：要画图就接生成式图像，不在这套矢量 DSL 上加级。判据阶梯只留第一级——书自己的图（figure catalog + `[fig:N]` + `view_figure`），成本为零，读者在书页上还会再遇到；现在在 `src/reading/figures/prompt.ts`，措辞收成「能引书里的图就引并讲那张图，否则用文字说清楚」。
