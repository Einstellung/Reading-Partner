info 的家是用户自己的办公室，照《Yes Minister》里大臣的私人办公室。一张静止插画，手机上竖构图。场景故意画得薄，分量在盒里装的东西。

## 场景

上半是一面格子柜，第一版 4 列 3 行；下半是书桌。桌后坐着一个代表用户的卡通小人，只有几个静止状态：埋头看文件、端着茶歇着。Lumen 坐在桌角，就是 [66](../companion/66-Lumen.md) 那一个，所以这一屏不再画 68 角上的 Lumen；别的屏上 68 照旧。

## 线与盒

info 替用户跑的每一件事叫一条线：每日简报、63 的每个研究室和专项组、73 的三餐、健康与健身，以后还会有别的。一条线一个红盒子，放在自己的格子里，格子上钉一块铜名牌。名牌上的字由代码叠在图上，不画进图里，所以开线、改名都不用出新图。格子位置固定，盒不因状态挪位。

60 的一盒（一次投递）和它的项属于一条线，柜里的红盒子是这条线的常设容器。一条线里有 `in box` 的项，就是「有新东西」。

盒的状态画得安静：

| 状态 | 画法 |
|---|---|
| 平常 | 只有盒 |
| 有新东西 | 盒盖缝里探出一张纸条 |
| 久没动静 | 落灰 |
| 线关了 | 纸封条加火漆，挪到柜子顶层 |

办公室里没有红色数字徽标，也不推送。

## 桌面

每天早上，或者有项到的时候，有新东西的线的盒从格子里取出来放到桌上，格子空着。桌上几个盒，就是今天有几件事在等。一个盒看完放回自己的格子。

小人跟着桌面：桌上有盒就在看文件，桌面空了就歇着。

## 打开

点一个盒，盒盖打开，这条线自己的页面全屏打开：简报的盒是当天简报；研究室的盒是它的态势、它的产品（比如合订本）和收链接的收件箱；三餐的盒是三餐页。要订成合订本的链接投进那条线的盒里。

## 批注

看完，用户在盒上写一行批注，像大臣在红盒子里的文件上批字（「这篇挖深一点」「这五篇订成一本」），然后把盒发回去。批注进这条线的常驻对话线程，按 tasking / run 执行（60、63、55）；结果回到同一个盒，盒带着新纸条回到桌上。

来回是异步的，像通信，每一封信都在干活。不另做写信功能。

## 开线

开新线在对话里说：点桌角的 Lumen，说一句。新盒带着名字出现在下一个空格子里。柜子满了就加柜位，怎么加待定。

## 别的屏

68 角上的盒在别的屏照旧，点它进办公室。

## 参考
