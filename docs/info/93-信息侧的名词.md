# 信息侧的名词

> 2026-10-22 项目发起人定。旧的每日简报页撤下，功能不动，以后以某种形式融回来；主推简报书架（[88](./88-主题搜索.md) 的每日简报和 [91](./91-专题调研.md) 的专题）。旧简报的界面由 `src/info/old-briefing.ts` 的 `OLD_BRIEFING_UI_ENABLED` 关着，改成 `true` 全部回来。旧链路见 [35](./35-简报漏斗.md)、[63](./63-情报局：研究室、专项组与态势.md)。

## 名词

| 英文 | 中文 | 指什么 |
|---|---|---|
| Intel | 信息 | info 这一侧整体的区域名，暂定 |
| Today | 今天 | 入口，开 app 落脚的页 |
| Briefs | 简报书 | 入口，简报的书架 |
| Meals | 三餐 | 入口 |
| Brief | 简报 | 卢明准备的文档。只有这一个词 |
| Daily | 每日 | 简报的一种：每晚一期的每日简报 |
| Study | 专题 | 简报的一种，也是单位：只看这一次的专题调研，临时的 |
| Lab | 研究室 | 单位，长期的 |
| Box | 盒子 | 卢明交回来的东西落的地方，点一张跳回原地（[68](../companion/68-Lumen与盒子的交互.md)） |

Briefing 退役，界面上不再出现。中文"简报"只指文档。

## 规则

- 界面里称呼信息侧整体的地方用 Intel / 信息。目前只有设置 › 功能里收集开关那一节的标题。
- 代码标识符不跟着改：`briefing`、`BriefingPage`、`settings.features.briefing` 这类 i18n 键、`InfoBriefingDeskRef` 等照旧。改名是以后单独的活。
