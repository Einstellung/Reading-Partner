# 情报局的其余机构

## 愿景

info 是一个情报局：研究室按章程盯一摊事，专项组是带到期日的研究室，编辑部把电报加工成稿。设计在 [63](../info/63-情报局：研究室、专项组与态势.md)、[60](../info/60-info：白宫与Red Boxes.md)、[65](../info/65-加工手册：常态模型、日更列表、滚雪球与稿.md)。已经在的是研究室与章程、态势与漂移检测、电报、分析员与综合、盒按室切、粗筛、采集端选举、tasking，本文是其余的。

## 为什么现在不做

源侧的规格差距等 [17](../info/17-信息源系统.md) 整体重做时一起补，不单独排（同 [podcast-video](./podcast-video.md)）。加工层的五层要有稳定的日更量才试得出好坏。

## 将来做时已知的事实

- 专项组只有类型位：`src/info/labs/types.ts` 的 `LabKind = "lab" | "study"`，注释写明只铸 `lab`。到期、零命中解散、薄态势、归档都没有。
- 招募员、数值管（`SeriesDescriptor`）、编辑部与督查、夜间 PC 预算、A 档源的 tier 与 Admiralty 双轴，src 里零命中。
- 60 定的 cable 八态状态字段一个都没有。反馈只有内存态的 dismissed / kept 和旧的 `info-feedback.jsonl`，三维度归因谈不上。
- 稿在 info 侧没有产物，书架没有 kind 字段。HTML 渲染面板已按 [67](../reading/67-HTML文档.md) 另走，不在这条线上。
- 65 五层的落地量是零：常态模型只有 `Picture.baseline` 一个自由文本字段（没有三层六字段、复核、缺字段进待答闸）；量级检查、日更列表、选题会四态与程序闸、滚雪球四状态、骨架与稿的模板、领域跟踪（合订本、周报、六步冷启动）、守则闭环与提示词版本号都没有。
- 源注册表离 17 那二十条规格的差距不当待办清单：17 本身定了要整体推翻重做。
- 源页仍有页内 URL 探测添加（63 说 add 只走对话），也不显示各被谁用。
