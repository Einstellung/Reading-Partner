# 桌宠的名字与自我介绍

> 2026-10-21 定。产品改名 Reading Partner → Lumen，角落里的桌宠让出这个名字，改成用户可设的名字，默认 Kris。本文是四步里的第一步，只做加法：目录、标识符、i18n key、产品名和界面上现有的「Lumen」字样都不动，后面的步骤再换。上游：[66](./66-Lumen.md) 的边界，[71](../soul/71-soul.md) 的 places 与角色，[136](./136-混合语音架构.md) 的前台。

## 名字

`settings.json` 里的 `companionName`，跟账号走、随同步（同 `meals`），不进 `device.json`。空串或全是空白就是默认名 Kris（`DEFAULT_COMPANION_NAME`）。读它一律经 `companionNameOf(settings)`：空白折成一个空格、去头尾、按字符截到 24 个、不是字符串的当没设。同步按 `fields` 策略单键合并，不需要字段组。设置 > Features 里有输入框（Show 开关下面一张卡，空着就是默认名、默认名做占位符、输入时按 24 字符截，离开输入框时折空白去头尾；`ui/components/settings/CompanionNameField.tsx`）。界面文案里指桌宠的字样用 `{name}` 占位，读取经 `ui/components/base/use-companion-name.ts`（由外壳从同一份 settings 喂入的模块级 store，同 `i18n/locale.ts` 的形状）；在 React 外拼的标题（`lumenToggleTitle`）把名字当参数传。i18n 的 key 名没动。

## 自我介绍

分两段：常驻的一段很短；长的一段是工具返回值，用户问「你是谁、这个 app 能干什么、怎么做某件事」时才进上下文。

常驻的一段是 `src/soul/intro.ts` 的 `introBlock(name)`，由 `soul/turn.ts` 拼在每个回合 system prompt 的最前面，在角色职责之前，所以门口、书、简报、复述、排练的对话都带它。三句，约 60 token：名字，它是 Lumen app 里住在每一屏角落的伙伴；边界；被问到自己、app 或怎么用时先调 `about_app`。字节只取决于名字，换工具不变，缓存前缀因此稳定（见坑 663）。锚定阅读桌的 prompt 是这段加一个空行，后面才是 docs/09 钉住的那段，那段本身仍逐字不变。

长的一段是工具 `about_app` 的返回值（`aboutAppText`），没有参数，描述是固定文字，不列地方和工具，所以工具列表的字节也不随回合变。它在 `turn.ts` 里和常驻段一起建，闭包住同样的输入。返回：名字和答法（报自己的名字，只说列出来的，不编功能，没列的就说这个 app 没有）；外壳登记的 places（`desk/places.ts`，每个地方一行 `id: about`）；这一回合伙伴自己的工具（角色的、soul 的、门口那种 surface 带的，每个一行 `名字: 描述第一句`，不含 `about_app` 自己）。桌上那样东西带来的工具由它自己的 prompt 讲，不进这里。外壳加一个屏、soul 多挂一个工具，返回值自动跟着变。它只读、不写、不设闸，进 durable 目录和工具花名册。

## 边界

照 [66](./66-Lumen.md)：不演想念、孤独、亲密，不提「多久没来」；它是读书、分析和处理用户材料的工具，不是人。这几句写在常驻段和语音前台里。

## 语音前台

前台走另一条 prompt 链（`soul/voice/front/context.ts`）。`frontIdentity(name)` 是口语版的身份：名字、是什么、边界、被问「你是谁」时一句话报名。它和 `FRONT_DUTY` 一起组成固定前缀（`frontFixedPrompt`），排在 place 和清单之前；名字在开通话时从设置读一次，改名下一通生效。

前台看不到工具的返回值，调不了 `about_app`。被问「你或这个 app 能干什么、怎么做某件事」时，它照答不了的问题处理，delegate 给 think 跑。think 跑的桌子是那个地方自己的回合（门口 `reading/turn/door-think.ts`、简报 `info-bell.ts`），`about_app` 是只读工具，跟着进去，跑的那边调它再写成口语答案。

## 其他人设句

和名字冲突的「你是……」改掉了：阅读 prompt 的「You are a reading companion embedded in a PDF reader」改成「Here you sit beside the user inside a PDF reader」；秘书职责改成「Here you are going through the user's daily briefing with them」；每日简报开场白（`info/issue/opening-record.ts`）的「You are Lumen」改成由调用方传入名字；加源引导里「介绍自己是阅读伙伴」改成「报自己的名字」。不面对用户的备课、讲义、蒸馏提示词里的「reading companion」不动。

## 没做的

本地 TTS 对自定义名字的读音（Kokoro 前端的中文走 jieba+pypinyin，多音字可能读错；英文名夹在中文里走英文词表，不在词表里的专名按字母拼读，非 ASCII 的拉丁字母会被丢掉）。`plugins/voice` 里「我是卢明」那句只是 G2P 的金标语料，没改。
