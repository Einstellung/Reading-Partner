# 82 手机阅读外壳

2026-09-28 定。依据是原型 Reader Chrome Prototype。滚动和翻页两种模式共用这一套外壳，正文视图见 [70](./70-手机读EPUB.md)、[79](./79-手机EPUB翻页.md)。

## 工具栏

默认收起，屏幕上只有正文、底部一行淡色页码，和 Learn 有新回复时右上角一个点。点正文中间调出顶栏（返回、书名、页码）和底栏（Outline、Display、Learn）；再点一次、翻页、滚动、打开任何面板都收起。翻页模式下左右各 28% 仍是翻页，中间才是工具栏。第一次打开书时屏幕中间提示一次「Tap the middle for tools / Hold a word to select」，5 秒后消失，每台设备一次（`phone-reader-hint`）。

没有笔架。划线和提问都从长按开始，AI pen 的置灰和原因文案删掉。

## 选中

长按一个词 500ms 选中这个词，不松手拖动按词扩展，松手后选区留着：两端出拖柄，上方弹出 Highlight | Ask。选区在视图的 overlay 里画（`.rp-select`，蓝色），拖柄和弹窗是外壳按视图报的视口矩形画的（`onSelection`）。拖柄拖动交给视图 `moveSelectionEnd`，另一端不动，移动端吸附到词边。有选区时，任何点按或滑动只清掉选区，不翻页、不开工具栏；翻页模式下路由的翻页被弹回原页。滚动时选区跟着正文走，外壳每个 scroll 事件重读矩形；改 Aa、尺寸变化、图片到达后的重排也不清选区，重排完再报一次矩形。

- Highlight：存成黄色划线。和已有划线重叠时合并成一条，旧的删掉（`mergeInto`）。
- Ask：存成 AI 下划线（`type: "underline"`、`AI_PEN_COLOR`），带新的 `aiThreadId`，同时在书的 threads 文件里建一条 mark 线程（`createThread`），然后打开这条对话。和 iPad 的 AI pen 同一种标注、同一种线程，iPad 上点它也能进。

## 点标注

- 黄线：Delete | Ask。Ask 先选中这条划线的字（`selectMark`），再照 Ask 走，下划线叠在黄线上。
- 紫线：Open | Delete。紫线穿过黄线时，一个弹窗里是 Open | Delete underline | Delete highlight（`FlowMarkPopup.under`）。
- 弹窗下面盖一层透明遮罩，点别处只收起弹窗，不翻页。
- 删带对话的标注照旧先确认，对话一起删（`delete-mark.ts`）。

## Learn

Learn 和一段话的对话都用同一个底部 sheet，高 85%，上面留出的一条页面就是遮罩，点它等于 Done。段落对话在标题下引出原文，输入框提示 Ask about this passage。打开一段话的对话后什么都没问就关掉，下划线和线程一起删掉（`leftEmpty`）。底栏的 Learn 永远进书级课堂；槽里是段落对话时，按 Learn 换成书级课堂。

## Outline 面板

一张固定高度的 sheet，三个页签 Outline | Marks | Prep，再开时停在上次看的页签（本次阅读内记住）。

- Outline：原来的目录。
- Marks：书里所有黄线和紫线，按正文顺序（`sortIndex`），每行是原文两行、所在章节和页码。点一行关面板、跳过去、描边 1.5 秒（`goToAnnotation`）。紫线那行右边有对话按钮。左滑露出 Delete，再点才删，手势用桌面标注列表的 `swipe-action.ts`。
- Prep：只读 iPad 或桌面备好、同步过来的章节脉络（`prep-<bookId>/chapters`）：章节关系图，然后每章一段；手机不跑备课。没有就说一句备课在 iPad 或电脑上做。

## Display

顶上一排 Scroll | Pages 分段控件，取代原来的 Turn pages 开关。

标注开关（2026-09-29）：Display 里一行 Marks，设置页「阅读」里一张卡片（只在手机外壳里画），是同一个值 `FlowDisplay.showMarks`，默认开，存在本机 `phone-display`，不同步。两处共用 `ui/components/base/usePhoneDisplay.ts`，一边改另一边立刻跟着变。关掉时 overlay 的 `.rp-marks` 子层不显示，点原来标注的位置不弹菜单，Marks 列表照常；只切这个开关不重排（`sameLayout`）。关着的时候存 Highlight 或 Ask 会自动打开，否则新划的线看不见。

## 结构

视图契约在 `flow-contract.ts`：`onSelection`、`onMiddleTap`，`moveSelectionEnd`、`saveSelection`、`clearSelection`、`selectMark`、`goToAnnotation`。选区的状态在 `flow-marks.ts`，两个视图只转发。外壳的纯逻辑（拖柄和弹窗位置、Marks 行、提示）在 `ui/components/phone/reader/reader-chrome.ts`，有单测。
